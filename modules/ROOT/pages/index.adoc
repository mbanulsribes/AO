== Proyecto CAOS, S.L.

Durante el curso trabajaremos como si formáramos parte del equipo de una empresa ficticia: *CAOS, S.L.*. Cada tema parte de una incidencia realista que tendrás que comprender, resolver, comprobar y documentar.

El objetivo no es únicamente aprender a usar aplicaciones ofimáticas, sino aprender a elegir la herramienta adecuada y trabajar con criterios profesionales.
