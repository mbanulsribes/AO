# Aplicaciones Ofimáticas · AsciiDoc + Antora

Repositorio nuevo para la web de alumnado de Aplicaciones Ofimáticas (1.º SMR).

## Desarrollo local

```bash
npm install
npx antora antora-playbook.yml
```

La web generada queda en `build/site/`.

## Contenido

Los temas están en `modules/ROOT/pages/` y la navegación en `modules/ROOT/nav.adoc`.
